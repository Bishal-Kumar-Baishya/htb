# Hack The Box Writeups

Collection of completed HTB machines documenting vulnerabilities, exploitation techniques, and privilege escalation methods.

## Completed Machines

| Machine | Difficulty | Type | Key Vulnerabilities |
|---------|------------|------|-------------------|
| [Appointment](https://app.hackthebox.com/machines/Appointment?sort_by=created_at&sort_type=desc) | Easy | Web | SQL Injection |
| [Cap](https://app.hackthebox.com/machines/Cap?sort_by=created_at&sort_type=desc) | Easy | Web | IDOR, Pcap Analysis, Linux Capabilities |
| [Sequel](https://app.hackthebox.com/machines/Sequel?sort_by=created_at&sort_type=desc) | Easy | Database | Unauthenticated Database Access |
| [Crocodile](https://app.hackthebox.com/machines/Crocodile?sort_by=created_at&sort_type=desc) | Easy | Web | Anonymous FTP Access, Exposed Credentials, Weak Authentication |


## Skills Practiced
- Network enumeration (Nmap)
- FTP enumeration and anonymous access
- Directory/file brute-forcing (Gobuster)
- SQL injection and database exploitation
- Packet capture analysis (Wireshark)
- Privilege escalation (Linux capabilities, SUID)
- Web application vulnerabilities (IDOR, weak auth)
- Credential harvesting and usage

## Tools Used
- Nmap
- FTP client
- Gobuster
- Wireshark
- Mariadb/MySQL CLI
- Python
- Linux
